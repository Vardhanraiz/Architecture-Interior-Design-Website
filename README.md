# Architecture & Interior Design Website

## 📌 Project Overview

This project is a modern architecture and interior design website created using HTML, CSS, and JavaScript. Inspired by contemporary website design concepts, it showcases architectural services, interior design work, and portfolio content through a clean and visually appealing layout.

The goal is to create an engaging online presence for an architecture or interior design studio.

## ✨ Features

- **Modern UI Design:** Clean layout with a professional visual style.
- **Hero Section:** Introduces the architecture and interior design studio.
- **About Section:** Presents information about the studio.
- **Services Section:** Highlights architecture and interior design services.
- **Portfolio Section:** Displays design and project imagery.
- **Contact Section:** Provides a section for contact information.
- **Navigation:** Allows users to move between different sections.
- **Responsive Layout:** Uses CSS styling and media queries to adapt the layout to different screen sizes.

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript

## 🚀 How to Run the Project

1. Clone or download this repository.
2. Open the project folder in Visual Studio Code.
3. Open `index.html` in your browser, or use the Live Server extension.
4. Explore the different sections of the website.
